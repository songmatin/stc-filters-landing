First Filter Guide

新手第一片濾鏡買什麼

第一次購買濾鏡時，不需要一次買齊所有種類。我會依照使用頻率、學習成本與拍攝效果是否容易判斷，安排一個比較容易開始的購買順序。

我的推薦順序

以下順序是以平常拍攝風景、建築、旅行與日常影像，希望先降低選擇難度的拍攝者為前提。

第一順位：AURA UV FILTER

如果主要需求是保護鏡頭前端，我會先從 AURA UV FILTER 開始。它的使用方向比較直接，不需要先學習偏光角度或高光控制，適合先熟悉安裝、清潔與收納。

  • 日常與旅行拍攝
  • 希望先處理鏡頭前端保護
  • 不想明顯改變影像氛圍

第二順位：PURE Hybrid CPL

如果經常拍攝風景、建築與旅行，或常遇到水面、玻璃與葉面反光，我會把 PURE Hybrid CPL 放在第二順位。STC 官方資料將它描述為低減光 CPL／保護鏡，約 `-0.5EV`，使用方向是偏光與保護，不是 ND 減光。

  • 風景與旅行
  • 建築與城市反光
  • 水面、玻璃或葉面

第三順位：Cine Mist 黑柔霧濾鏡

如果已經確定自己喜歡夜景、逆光、城市燈光或柔化高光的影像風格，可以再考慮 Cine Mist。它比較偏向影像氛圍與視覺風格，不是處理所有拍攝問題的通用濾鏡。

  • 夜景
  • 逆光
  • 城市燈光
  • 希望調整高光與影像氛圍

第四順位：MagVario 磁吸濾鏡套組

如果拍攝流程經常需要快速切換不同濾鏡，可以考慮 MagVario。它的重點是能否改善你的實際拍攝流程；若目前還沒有固定的濾鏡使用習慣，通常不需要優先從系統型套組開始。

  • 需要快速切換濾鏡
  • 經常外拍或旅行
  • 已經有固定拍攝流程

我的實拍判斷

我會先用 CPL 處理拍攝現場真正影響主體的反光，而不是為了讓天空變深就一直使用。當場景的反光並不明顯時，CPL 的必要性就會下降。

黑柔霧則是我在夜景、逆光或城市光源較多時才會考慮的選擇，因為它的效果很依賴畫面中的光源位置。當畫面缺少明確高光時，柔化效果可能不明顯，使用後也不一定比原本的影像更適合。

簡單選擇方式

  • 以鏡頭前端保護為主：AURA UV FILTER
  • 以風景、旅行與反光控制為主：PURE Hybrid CPL
  • 以夜景與影像氛圍為主：Cine Mist
  • 以快速切換與拍攝流程為主：MagVario

購買前確認

  • 鏡頭或設備型號
  • 鏡頭前端濾鏡口徑
  • 是否需要轉接環
  • 商品是否適用於目前設備
  • 官方商品頁是否列出相容性
  • 折扣碼是否適用於該商品

常見問題

新手第一片濾鏡應該買哪一種？

如果主要需求是鏡頭前端保護，可以先從 AURA UV FILTER 開始；如果主要拍攝風景、旅行或反光場景，可以優先考慮 PURE Hybrid CPL。

UV 保護鏡、CPL 與黑柔霧濾鏡可以互相取代嗎？

不能。三者的使用目的不同，分別偏向鏡頭保護、反光控制與影像氛圍。

新手需要一次買很多濾鏡嗎？

不需要。先從最常遇到的拍攝問題開始，確認自己真的會使用，再逐步補充其他類型。

PURE Hybrid CPL 是 ND 濾鏡嗎？

不是。STC 官方將 PURE Hybrid CPL 定位為低減光 CPL／保護鏡，ND 則是另外的產品類型。

買濾鏡前最重要的是什麼？

先確認設備相容性與鏡頭濾鏡口徑，再依照自己的拍攝題材選擇濾鏡類型。
